## 酒馆读卡 SillyTavern extension

The independent 酒馆读卡 extension reuses this project's reader-domain module.
It loads host APIs from [SillyTavern](https://github.com/SillyTavern/SillyTavern)
at runtime; the SillyTavern application is not bundled in this delivery.

The API connection interaction was inspired by **LittleWhiteBox by biex**:
https://github.com/RT15548/LittleWhiteBox
This is a user-interface reference only; no LittleWhiteBox implementation is
copied into the extension.
